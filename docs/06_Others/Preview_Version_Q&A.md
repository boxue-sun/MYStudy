## 智路OS Preview版 Q&A
2022年8月发布了智路OS Preview版，面向不同开发者角色提供了不同的源码、SDK和工具，支持开发者对智路OS整体框架进行快速验证。在发布智路OS1.0 Beta版本后，我们对代码库结构进行了优化和调整。

我们将Preview版中Gitee社区提出的问题整理至本文档，希望能为您提供参考。

**A**：感谢您的关注！根据项目实践，智路开源社区为不同类型开发者提供了不同的使用方法。

- （1）应用开发者
Preview版的airos sdk的接口和真实环境中的接口保持一致，通过这些接口，开发者可以获取脱敏后的真实环境中的障碍物结构化数据、事件检测结果、交通信号灯消息、局部地图消息等。开发者可以基于开放数据自行完成如『交通事件检测』和『V2X场景』等应用。

     **注** ：在`1.0Beta`版本中，这一模块已整合进入[路侧应用](https://gitee.com/ZhiluCommunity/airos-edge/blob/master/docs/README_AIROS_EDGE.md)和[车端应用](https://gitee.com/ZhiluCommunity/airos-vehicle)代码库。

- （2）硬件设备开发者
通过设备抽象层，开发者可以开发新的设备driver，并添加到airos的可支持设备列表。

    **注** ：在`1.0Beta`版本中，这一模块已整合进入[传感器设备抽象层](https://gitee.com/ZhiluCommunity/airos-edge/blob/master/base/device_connect/traffic_light/README.md)

- （3）学习研究
开发者可以通过了解内核和中间件的开发细节并对其进行能力扩展。中间件和内核开源链接如下：

      内核 https://gitee.com/ZhiluCommunity/airos-kernel

      中间件 https://gitee.com/ZhiluCommunity/airos-middleware

    **注** ：在`1.0Beta`版本中，这一模块已分散整合进入各个代码库，原链接将会在近期失效。
