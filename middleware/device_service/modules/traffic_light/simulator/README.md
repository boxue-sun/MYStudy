## GAT1743协议模拟器

### 运行
```bash
python3 gat1743_simulator.py
```

### 信号机方案色步配置文件内容说明
使用者可通过修改`signal_scheme.json`文件自定义模拟器的配置，支持修改灯组类型、周期等。  
相关定义如下所示：

```
灯颜色: 
    0-黑灯 1-绿  2-黄  3-红    11-绿闪  12-黄闪  13-红闪
灯类型(type):
    1：直行方向指示信号灯
    2：左转方向指示信号灯
    3：右转方向指示信号灯
    4：机动车信号灯
    5：左转非机动车信号灯
    6：右转非机动车信号灯
    7：非机动车信号灯
    8：人行横道信号灯
    9：掉头信号灯
    10：车道信号灯
    11：道口信号灯
    12：闪光警告信号灯
    13：有轨电车专用信号灯（直行）
    14：有轨电车专用信号灯（左转）
    15：有轨电车专用信号灯（右转）
入口朝向角度：
    0-北 90-东 180-南 270-西
灯组号：
    1~n，信号灯灯组

周期方案(step)内容格式如下：
    入口朝向角度:{
        灯组1: (灯类型, ((灯颜色1, 时长1), (灯颜色2, 时长2), (灯颜色3, 时长3)))
        灯组2: (灯类型, ((灯颜色1, 时长1), (灯颜色2, 时长2), (灯颜色3, 时长3), (灯颜色1, 时长4)))
        灯组3: (灯类型, ((灯颜色1, 时长1), (灯颜色2, 时长2)))
        ...
    }
    ...
```
